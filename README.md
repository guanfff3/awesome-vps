# 📌 How This List Works

This repository is designed as a practical starting point for comparing VPS options.

### Price

Plans are grouped by their listed monthly price.

Annual plans are also shown using an approximate effective monthly cost.

### Specifications

The main specifications shown are:

- CPU / vCPU
- RAM
- Storage
- Traffic / bandwidth
- Billing period
- Price

### Selection

The list focuses on plans that are useful for:

- Budget VPS
- Websites
- Development
- Docker
- Self-hosting
- Databases
- High-memory workloads
- Storage-heavy workloads

This is a curated resource list, not a universal ranking of VPS providers.
